# Better Fines 0.11.5

Better Fines adds speeding, red-light, wrong-way, and optional pedestrian-hit
fines to Big Ambitions.

This release fixes the first-ticket HUD failure caused by incompatible copies of
the shared UI library. If the normal panel cannot be created, Better Fines
switches automatically to a dependency-free compatibility HUD while traffic
enforcement continues normally.

Requires **LIB BA Player Location 0.11.1+**. Better Pedestrians and Speedometer
remain optional companion mods.
